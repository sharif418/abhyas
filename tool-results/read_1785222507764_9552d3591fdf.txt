     1→# অভ্যাস (Abhyas) — Project Worklog
     2→
     3→## Project Overview
     4→**অভ্যাস** is a premium, fully-Bengali self-discipline / habit-tracking Progressive Web App
     5→(PWA) built with Next.js 16. It is the web adaptation of a mobile-app proposal
     6→(React Native + Kotlin) — the proposal explicitly allowed a Next.js PWA path, which is
     7→the senior-architect choice for this environment.
     8→
     9→**Core USP**: Deep Islamic integration (prayer tracking, Quran reading, duas, tasbih) +
    10→offline-first persistence + Bengali-first UI + gamification, targeted at Bangladesh users.
